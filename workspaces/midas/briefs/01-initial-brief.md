# Midas - Autonomous Investment Management Platform

## User Brief

**Date**: 2026-03-23

### Context

- User has $5M in investment capital
- Wants a fully autonomous system that invests without manual intervention
- Wants to productize it to manage investments for other people as well

### Core Requirements

1. **Autonomous Investment**: System must independently make investment decisions and execute trades without human intervention
2. **Multi-Client Support**: Must scale from personal use to managing investments for multiple clients
3. **Product-Ready**: Should be a complete product, not just a personal tool

### User's Words

> "I have 5M in my account and I heard that investing is the way to go. I would like to build a software/app/system or whatever you call it, so that I do not need to do a thing and this system will autonomously invest for me. If possible, we should make it into a product so that I can manage investments for other people as well."
